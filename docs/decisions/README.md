# Active Decisions

Use this directory for durable decisions that need context, rationale, and constraints.

Move a decision to `archive/` when it has been fully implemented, superseded, or no longer needs to stay in the active decision list.

Decision files should use:

```md
# YYYY-MM-DD: Decision title

## Context

## Decision

## Reason

## Constraints Introduced

## Do Not Change Casually
```
