# Living Design Docs

Use this directory for design documents that should guide current and future implementation.

The initial v0.1 design proposal remains in `mkworld_stats_manager_docs_v0_1/`. When a proposal becomes an active implementation rule, summarize or rewrite it here instead of editing the snapshot casually.

Recommended files:

- `architecture.md`
- `database.md`
- `api.md`
- `frontend.md`
- `deployment.md`
