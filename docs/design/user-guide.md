# MKWorld Stats Manager ユーザーガイド

日常的な操作リファレンス。実装背景やハンドオフの読み込みは不要。

**アクセス先**: `http://192.168.1.205:3030`（LAN 内のみ）

---

## 1. 概要

Mario Kart World の個人プレイ記録・分析ツール。

- 野良VR（ランクマッチ）のコース記録と VR 推移管理
- Lounge マッチのコース・スコア・順位記録と MMR 同期
- コース/ルート別ノートおよびマップアノテーション
- 記録の修正・取消・非表示管理

現在は LAN 内からのみアクセス可能。外部公開設定は入っていない。

---

## 2. 起動前の確認

### バックエンド状態の確認

ページ上部ヘッダーでは、バックエンドとDBへの接続状態を確認できます。起動時と30秒ごとに確認し、「再確認」ボタンで手動確認することもできます。5秒以内に応答がない場合は確認失敗として表示します。
DB接続エラーの場合はDBへの疎通に失敗しています。APIへの接続失敗やタイムアウトの場合は、バックエンド停止だけでなく通信経路の問題も考えられます。`docs/design/operations.md` のポストデプロイチェックを参照してください。
これは接続確認であり、すべての記録やDBスキーマが正常であることを保証する表示ではありません。

### 設定の確認

**Settings** タブを開き、以下を確認する。

| 確認箇所 | 内容 |
|---|---|
| VR アカウント | 使用するアカウントに「有効」タグが付いているか |
| 初期 VR / 現在 VR | 実際の値と一致しているか |
| ラウンジプレイヤー ID | MKCentral の数値 ID またはプレイヤー名 |
| シーズン | 現在のラウンジシーズン番号 |
| 自動同期 | Lounge セッション終了時に MMR を自動取得する場合はオン |

Settingsには、フロントエンドとバックエンドそれぞれのコミットID・ビルド日時（日本時間）も表示します。フロントエンドはブラウザが読み込んだ画面、バックエンドは現在応答しているAPIの版です。両者のコミットが異なる場合は、Portainerでの更新状況とブラウザの再読み込みを確認してください。ローカルビルドなど、情報が渡されていない場合は不明として表示します。

## 3. 野良VR の記録

### セッション開始

1. **Playing** タブを開く。
2. 「野良VR を開始」ボタンを押す。  
   アクティブアカウントと現在 VR が表示されていることを確認。

### コース選択（Step 1: Target）

3. マップ上のポイントをクリックするか、テキストリストで「出発地点」を選ぶ。
4. 通常コース（3周）の場合は「到着を出発と同じにする」ボタンを押す。  
   道中コースの場合は到着地点を別途選ぶ。
5. 「コースを確認」ボタンを押す。

### アシスト情報の確認（Step 2: Assist）

6. コース名・種別（通常/道中）が表示される。
7. 設定済みのノートやアノテーションがあればここに表示される。
8. 問題なければ「結果を入力する」ボタンを押す。

### 結果入力（Step 3: Result）

9. **参加人数**（12人 / 24人）を選ぶ。  
   セッション開始時のデフォルト値が入っているが変更可能。
10. **順位**を入力する（±ボタンまたは直接入力）。
11. **結果VR**（レース後の実際の VR）を入力する。  
    VR デルタ（増減）は「現在 VR → 入力値」から自動計算されてリアルタイム表示される。
12. 「保存して次のコースへ」を押す。  
    コース選択画面に戻り、次のレースを記録できる。

### セッション終了

- サイドバーの「マッチ終了」ボタンを押す。  
  セッションは `completed` 状態になる。
- 終了前に入力ミスがあれば「直前のレースを Undo」ボタンで取り消せる。

## 4. Lounge の記録

### セッション開始

1. **Playing** タブを開く。
2. 「Lounge を開始」セクションで参加人数（12人 / 24人）とフォーマット（FFA / 2v2 / 3v3 / 4v4 / 6v6）を選ぶ。
3. 「Lounge を開始」ボタンを押す。

### コース選択（Step 1: Target）

野良VR と同様に出発・到着地点を選んで「コースを確認」を押す。

### 結果入力（Step 3: Result）

4. **順位**を入力する。
5. **スコア**（そのレースの獲得ポイント）を入力する。
6. 「保存して次のコースへ」を押す。

### 警告について

リピック（同じコースを再度選ぶ）や人数制限などの場合、黄色い警告ボックスが表示される。  
警告は通知のみで、記録の保存を妨げない。そのまま保存して問題ない。

### 自動終了と手動終了

- 12 レース記録が完了すると、セッションは自動的に `completed` になる。  
  完了メッセージが表示されたら「セッション選択に戻る」を押す。
- 12 レース未満で終える場合はサイドバーの「マッチ終了」ボタンを押す。

### MMR 自動同期

Settings で「自動同期を有効にする」がオンの場合、セッション完了時に MKCentral から MMR が自動取得される。  
ヘッダー近くに同期結果メッセージが表示される。失敗した場合は Lounge タブから手動で「MMR 同期」できる。

## 5. 記録の修正

**Records** タブでセッション一覧を表示し、対象セッションをクリックするとレース詳細が開く。

### フィールドの修正

各レース行の「編集」ボタンを押すと以下を修正できる。

| フィールド | 対象 |
|---|---|
| 人数 | 野良VR / Lounge 共通 |
| 順位 | 野良VR / Lounge 共通 |
| 結果VR | 野良VR のみ |
| スコア | Lounge のみ |
| メモ | 任意テキスト |

修正後「保存」を押す。

> 注意: 野良VR の `結果VR` を修正しても、Settings の VR アカウント `現在 VR` は更新されない。  
> `現在 VR` を直す場合は Settings タブ → VR アカウント → 「編集」から手動で修正する。

### 取消と非表示の違い

| 操作 | 意味 | 履歴への残り方 |
|---|---|---|
| 取消 | レースは実施されたが無効になった（キャンセルレースなど） | 取消タグ付きで残る。分析からは除外される |
| 非表示 | 誤入力したレースを通常の履歴・分析から除外したい | 非表示タグ付きで残る。「非表示も表示」チェックボックスで確認可能 |

非表示にしたレースは「表示に戻す」ボタンで復元できる。

## 6. コース / ノート / アノテーション

**Courses** タブ（内部名: NotesView）を開く。

### ターゲット選択

1. 上部のセグメントボタンで「コース」または「ルート」を選ぶ。
2. ドロップダウンから対象を選ぶ。

ノートとアノテーションは選択したターゲットにスコープされる。  
別のターゲットに切り替えると、そのターゲットのノートだけが表示される。

### ノートの作成

3. 「ノートを作成」フォームにタイトル・本文を入力する（どちらも省略可）。
4. ピン留めや優先度を設定するとノートが上位に表示される。
5. 「作成」を押す。

既存ノートは「編集」「削除」で管理できる。

### アノテーション（マップ書き込み）

ノート一覧の下にアノテーションエディタが表示される。

- **配置**: エディタ上をクリックするとマーカーを置ける。
- **移動**: 編集モードで既存マーカーをドラッグすると位置を変えられる。
- ルート/コースの画像アセットが存在する場合はその画像が背景として表示される。  
  アセットがない場合はフォールバックパネルが表示される。

## 7. Analytics / Lounge ビュー

### Dashboard

全体のクイック概要。

- アクティブ VR アカウントと現在 VR
- 進行中セッション
- ライブラリ統計（コース数、ルート数、ノート数、アノテーション数）
- 最近のセッション一覧

### Analytics（VR Analytics）

野良VR に特化した分析。

- セッション数・完了レース数
- VR デルタ（合計・平均・Best・Worst）
- 順位分布
- よく使うコース/ルートランキング
- 直近のランクセッション一覧

非表示・取消レコードは通常メトリクスから除外される。

### Lounge

Lounge マッチに特化した分析。

- セッション数・完了レース数・平均順位・平均スコア
- 12p/24p MMR と推移グラフ
- 「MMR 同期」ボタンで手動同期可能
- 警告レコード一覧
- よく使うコース/ルートランキング

## 8. データリセットとバックアップ

詳細は `docs/design/operations.md` を参照。

バックアップは `pg_dump` で取得し、`/mnt/nas/pi_backup/` に保管する。  
記録のみのリセット（マスタデータを残したままユーザーデータを削除）には `scripts/record_only_cleanup.sql` が使える。  
必ずバックアップを取ってから、内容を確認した上で実行すること。フルリセット（PostgreSQL データディレクトリの削除）は operations.md を参照。

## 9. OBS 配信オーバーレイ

現在の VR または Lounge MMR を OBS のブラウザソースとして表示できる。

### オーバーレイ URL

Settings タブの「OBS 配信オーバーレイ」セクションから各 URL をコピーできます。

| URL | 表示内容 |
|---|---|
| `http://192.168.1.205:3030/?view=overlay&mode=vr` | アクティブアカウントの現在 VR |
| `http://192.168.1.205:3030/?view=overlay&mode=mmr` | Lounge MMR（Settings の `lounge_game` に応じて 12p/24p を自動選択） |
| `http://192.168.1.205:3030/?view=overlay&mode=auto` | Lounge セッション進行中は MMR、Ranked セッション進行中は VR、それ以外は VR と MMR を約8秒ごとに交互表示 |

### オプションパラメータ

| パラメータ | 効果 |
|---|---|
| `&compact=1` | モード切り替えボタンを非表示にする |
| `&bg=solid` | 半透明の暗い背景を付ける（クロマキー不要の環境向け） |

### 値の更新

2 秒ごとにポーリングされる。

- VR: Settings でアカウントの現在 VR を編集するか、Ranked レース結果を保存すると反映される。
- MMR: Lounge MMR 同期（自動または手動）が成功すると反映される。

バックエンドとの接続が切れた場合は最後に取得した値を表示し、「接続なし」インジケータを表示する。

### OBS 設定

- ブラウザソースのサイズは **320×120** または **480×160** 程度を推奨。
- 背景を透過させる場合は OBS の「ブラウザソースの透明度を有効にする」にチェックを入れる（`bg=solid` を使う場合は不要）。

## 10. トラブルシューティング

| 症状 | 対処 |
|---|---|
| フロントエンド再デプロイ後に UI が古いまま | ブラウザで `Ctrl+Shift+R`（Mac: `Cmd+Shift+R`）を押してハードリロードする |
| MMR 同期で「対応する完了済み Lounge セッションが見つかりませんでした」と表示される | MKCentral の MMR 変動タイムスタンプがセッション完了時刻から ±2 時間外にある。手動でのリトライか、セッション終了直後に再試行する |
| Portainer 再デプロイ後にポートが変わる | スタック環境変数に `FRONTEND_PORT=3030` / `BACKEND_PORT=8001` が設定されているか確認する。詳細は `docs/design/operations.md` の「Portainer Stack Environment Variables」を参照 |
