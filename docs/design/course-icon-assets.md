# Course Icon Assets

## Path Convention

```text
frontend/public/assets/course-icons/<course_id>.png
```

Runtime URL: `/assets/course-icons/<course_id>.png`

## Usage Notes

- Assets are local-only. Do not hotlink external image URLs at runtime.
- Files may be user-provided or sourced from approved reference pages (see `docs/decisions/2026-05-25-map-image-asset-policy.md`).
- When a file is missing, `WorldMapPicker` falls back to a two-character text marker.
- Do not resize or recompress user-provided images unless explicitly requested.
