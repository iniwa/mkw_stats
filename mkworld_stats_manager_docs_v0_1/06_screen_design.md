# MKWorld Stats Manager 画面設計 v0.1

## 1. 画面一覧

| 画面 | 目的 |
|---|---|
| ダッシュボード | 現在VR/MMR、未完了記録、主要導線 |
| プレイ中表示 | コース選択、メモ確認、レース記録 |
| 戦績一覧 | VR/Lounge記録の一覧・検索 |
| グラフ・分析 | VR/MMR推移、コース別成績 |
| コース図鑑 | コース・道中・メモ閲覧 |
| コースメモ編集 | 付箋メモ・ピン・画像管理 |
| ビルド研究 | キャラ/マシン性能確認・比較 |
| アイテムテーブル | 順位帯・人数別アイテム確認 |
| Lounge同期 | 手動更新・継続更新・Table一覧 |
| 設定 | VRアカウント、Lounge ID、使用構成 |

## 3. ダッシュボード

表示:

- 現在VR
- 現在MMR
- 今日のレース数

- 直近7日のMMR増減
- 野良VR開始
- Lounge開始
- Lounge更新
- 未完了記録
- active session
- 得意/苦手コース

## 4. プレイ中表示

状態:

| 状態 | 内容 |
|---|---|
| session_select | 野良VR / Loungeを開始 |
| course_select | コースを選択 |
| course_confirm | 選択したコースを確認 |
| course_view | メモ・マップ・警告を表示 |
| ranked_result_input | 野良VR結果を入力 |
| lounge_recorded | Loungeコース記録完了 |
| session_finished | マッチ終了 |

### セッション開始

```text
プレイ中表示を開始

[野良VR]
現在アカウント: main / VR 8420

[Lounge]
形式: [12人] [24人]
フォーマット: [FFA] [2v2] [3v3] [4v4] [6v6] [8v8] [12v12]

[開始]
```
