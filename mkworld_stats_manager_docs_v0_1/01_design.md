# MKWorld Stats Manager 設計ドキュメント v0.1

## 1. 概要

MKWorld Stats Manager は、マリオカートワールド向けの個人用戦績・攻略補助ツールである。

主な目的:

- 公式オンライン野良マッチのVR記録
- MKCentral LoungeのMMR・Table情報管理
- コース別成績分析
- コース攻略メモ管理
- プレイ中のコースメモ確認
- Lounge中のコース履歴管理
- リピック警告
- キャラ/マシン性能確認
- アイテムテーブル確認

## 2. 実行環境

- Raspberry Pi 上でホスト
- Docker Compose で構成
- 初期運用はLAN内アクセスのみ
- 外部公開はMVP範囲外

## 3. 用語

| 用語 | 意味 |
|---|---|
| VR | 公式オンライン野良マッチのレート |
| MMR | MKCentral Lounge上のレート |
| Lounge | MKCentral Loungeの対戦・成績システム |
| Race | 1レース単位の記録 |
| Table | Loungeにおける複数レースの試合単位 |
| Course | 通常の3周コース |
| Route | 道中コース、接続ルート型コース |
| Draft Race | コースのみ入力済みで、結果未入力のレース記録 |
| Completed Race | 結果または記録が完了したレース記録 |
| Playing Session | プレイ中表示で進行中の一連の記録セッション |
| VR Account | 野良VRを記録する対象アカウント |

## 4. 設計方針

### 4.1 VRとLoungeの扱い

| 種別 | 表示名 | 取得方法 | レート |
|---|---|---|---|
| 野良 | VR | 手入力 | VR |
| Lounge | Lounge | API同期 + 必要に応じた手入力 | MMR |

VRとLoungeは同じアプリ内で扱うが、レートの意味と取得方法が異なるため、データ上は明確に分離する。

### 4.2 プレイ中UI

野良VRとLoungeで、プレイ中UIを大きく分けない。

共通の流れ:

```text
コース選択
  ↓
コース確認
  ↓
メモ表示
  ↓
レース
  ↓
結果または記録入力
  ↓
次のコース選択
```

| 機能 | 野良VR | Lounge |
|---|---:|---:|
| コース選択 | 有効 | 有効 |
| コースメモ表示 | 有効 | 有効 |
| マップクリック選択 | 有効 | 有効 |
| VR増減入力 | 有効 | 無効 |
| 1マッチ中のコース履歴 | 任意 | 有効 |
| リピック警告 | 任意 | 有効 |
| Lounge更新 | 無効 | 有効 |
| Lounge継続更新 | 無効 | 有効 |

### 4.3 API取得の前提

- 公式野良VRはAPI取得できない前提
- Lounge APIはTable単位・プレイヤー単位の情報取得を基本とする
- Lounge APIからレース単位の詳細コース情報は取得できない前提
- コース単位の記録が必要な場合は、野良VR・Loungeともにプレイ中UIで手入力する

## 5. コース選択

コース選択は、マリオカートワールドの全体マップに近い画像を用いたクリック方式を基本とする。

```text
1. 出発地点をクリック
2. 到着地点をクリック
3. 確認ダイアログを表示
4. 確定
```

3周コースの場合:

```text
DK Pass → DK Pass
```

道中コースの場合:

```text
Peach Stadium → Rainbow Road
```

確定前には必ず確認する。

```text
DK Pass → DK Pass でいいですか？
[はい] [選び直す]
```

## 6. Lounge設計

- Loungeは共通プレイ中UIを使う
- リピック防止はLounge限定機能の一部であり、Lounge全体の主目的ではない
- Loungeは1マッチ12レースとして扱う
- `Race 4 / 12` のように現在レース番号を表示する
- 12レース目の記録完了時に自動でマッチ終了
- 手動のマッチ終了ボタンも用意
- 警告は表示するが、記録は可能

## 7. Lounge同期

Lounge同期は手動更新を基本とする。

### 手動更新

- 「更新」ボタンを押した時にLounge APIから最新情報を取得
- 自前DBにTable情報・MMR情報を保存

### 継続更新

- マッチ終了後の利用を想定
- 3分ごとにAPI確認
- 以下で停止:
  - 新規TableまたはMMR更新を検知
  - 1時間更新なし
  - ユーザーが手動停止
  - APIエラーが連続

## 8. コースメモ

- 付箋型メモ
- 複数作成可能
- 優先度を持つ
- タグを持つ
- 表示数は固定制限しない
- セクションごとにスクロール可能
- マップ上ピンはホバーで対応メモを表示

## 9. 分析

- VRとMMRは別系列で表示
- VR推移
- MMR推移
- 日別/週別/月別増減
- コース別成績
- 通常コースと道中コースは別集計

指標:

| 指標 | 定義 |
|---|---|
| 上位率 | 上位として記録された割合 |
| 中位率 | 中位として記録された割合 |
| 下位率 | 下位として記録された割合 |
| 平均増減 | そのコースでのVR/MMR増減平均 |
| 試行回数 | 記録されたレース数 |
