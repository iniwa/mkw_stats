# MKWorld Stats Manager プレイ中表示設計 v0.1

## 1. 基本方針

プレイ中表示は、野良VRとLoungeで大きく分けない。

共通UIを使い、モードごとに一部機能を有効化・制限する。

| 機能 | 野良VR | Lounge |
|---|---:|---:|
| コース選択 | 有効 | 有効 |
| メモ表示 | 有効 | 有効 |
| マップ上のコース選択 | 有効 | 有効 |
| レースごとのVR入力 | 有効 | 無効 |
| 1マッチ分のコース履歴記録 | 任意 | 有効 |
| リピック警告 | 任意 | 有効 |
| マッチ終了ボタン | 有効 | 有効 |
| Lounge更新ボタン | 無効 | 有効 |
| Lounge継続更新ボタン | 無効 | 有効 |

## 2. 共通フロー

```text
コース選択
  ↓
コース確認
  ↓
メモ表示
  ↓
レース
  ↓
結果または記録入力
  ↓
次のコース選択
```

保存後は、原則として次のコース選択に戻る。

プレイを終了する場合は「マッチ終了」ボタンを押す。

## 3. アカウント選択

VRアカウント選択はプレイ中UIでは行わない。

設定画面で事前に選択する。

プレイ中UIでは、現在選択中のVRアカウント名と現在VRのみ表示する。

## 4. 画面構成

```text
┌────────────────────────────────────┐
│ Header                              │
│ Mode: 野良VR / Lounge               │
│ Course: 未選択 or 現在のコース       │
│ Race: 4 / 12                        │
├──────────────────────┬─────────────┤
│ 左: 全体マップ          │ 右: 情報     │
│ - 出発地点クリック       │ コース名     │
│ - 到着地点クリック       │ メモ一覧     │
│ - ピン/アイコン表示      │ 警告         │
├──────────────────────┴─────────────┤
│ [戻る] [保存] [次へ] [マッチ終了]     │
└────────────────────────────────────┘
```

## 5. コース選択

### 5.1 マップクリック

```text
1. 出発地点をクリック
2. 到着地点をクリック
3. 確認ダイアログを表示
4. 確定
```

### 5.2 通常3周コース

同じ地点を2回クリック。

```text
DK Pass → DK Pass
```

### 5.3 道中コース

異なる地点をクリック。

```text
Peach Stadium → Rainbow Road
```

### 5.4 確認

```text
DK Pass → DK Pass でいいですか？
[はい] [選び直す]
```

警告がある場合:

```text
⚠ DK Pass は Race 2 で走行済みです。
それでも記録しますか？

[記録する] [選び直す]
```

## 6. メモ表示

- コース名
- 道中の場合は出発地点・到着地点
- コースマップ
- マップ上ピン・アイコン
- メモ一覧
- タグフィルター
- コース別成績
- Lounge警告

メモは優先度順に表示する。  
表示数は固定制限しない。  
メモ領域をスクロール可能にする。

## 7. 野良VR結果入力

```text
DK Pass の結果

参加人数:
[12] [24]

順位帯:
[上位] [中位] [下位]

VR増減:
[-] [ 48 ] [+]

現在VR:
8420 → 8468

[保存して次へ]
[保存]
[マッチ終了]
```

## 8. Lounge記録

Loungeでは、コース確定時点でそのレースの記録を完了扱いにする。

```text
Race 4 / 12

記録しました:
DK Pass

警告:
⚠ Race 2で走行済みです。

走行済みコース:
1. Mario Bros. Circuit
2. Crown City
3. DK Pass
4. DK Pass ⚠

[次のコース]
[Undo]
[マッチ終了]
```

12レース目を記録したら、自動でマッチ終了状態に進む。

## 9. マップ上ピン

- ピン
- アイコン
- 矢印
- テキスト
- 範囲

ピンにマウスホバーすると対応メモを表示する。

```text
ピンにホバー
  ↓
「ここでキノコ使用。インを切りすぎると落下注意」
```

## 10. スマホ対応

初期段階ではスマホ最適化を強く優先しない。  
PCまたはタブレットでの操作性を優先する。
